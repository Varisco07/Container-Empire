# Container Empire

> A container-opening simulator built with Flutter — think CS:GO cases meets Pokémon collection, with deep progression, mutations, and live events.

---

## Features

- **8 Rarity tiers** — Common → Mythic, each with distinct glow effects and animated reveals
- **5 Mutation types** — RNG-driven item mutations that alter appearance and market value
- **Advanced RNG engine** — Luck boosts, event multipliers, and seed-based provably fair drops
- **Roulette + Flame Engine animations** — Smooth 60 FPS container opening sequence
- **Full inventory system** — Filter, search, sort, lock items, sell single / bulk / all
- **Progression system** — XP, levels, upgrade tree, daily/weekly/permanent missions
- **Live events** — Remote Config–driven events (Lucky Weekend, Galaxy Week, etc.)
- **Monetization-ready** — Rewarded ads, IAP gem packs, VIP Pass, Battle Pass

## Getting Started

### 1. Prerequisites

| Tool | Minimum version | Download |
|---|---|---|
| Flutter SDK | 3.3.0 | [flutter.dev/docs/get-started/install](https://flutter.dev/docs/get-started/install) |
| Dart SDK | 3.3.0 | Included with Flutter |
| Git | any | [git-scm.com](https://git-scm.com) |
| Chrome | any | Required for `flutter run -d chrome` |
| Firebase CLI | latest | `npm install -g firebase-tools` |
| FlutterFire CLI | latest | `dart pub global activate flutterfire_cli` |

> **Windows only:** after installing Flutter, add the `bin` folder to your PATH:
> ```powershell
> # Run once in PowerShell (then restart the terminal)
> $env:Path += ";C:\flutter\bin"
> [System.Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\flutter\bin", "User")
> ```
> Verify with: `flutter --version`

---

### 2. Clone the repo

```bash
git clone https://github.com/<your-username>/container-empire.git
cd container-empire
```

---

### 3. Install dependencies

```bash
flutter pub get
```

---

### 4. Generate Hive adapters

The project uses Hive for local persistence. The type adapters must be generated before the first build:

```bash
dart run build_runner build --delete-conflicting-outputs
```

Re-run this command any time you change a `@HiveType` model.

---

### 5. Configure Firebase ⚠️

The file `lib/core/config/firebase_options.dart` is **not committed** to the repo — it contains project-specific keys. You must generate it yourself:

```bash
# 1. Log in to Firebase
firebase login

# 2. Link to your Firebase project and generate the config
flutterfire configure
```

This will create `lib/core/config/firebase_options.dart` automatically. Make sure your Firebase project has the following services enabled:
- Authentication (anonymous + Google)
- Firestore Database
- Remote Config
- Analytics
- Crashlytics

---

### 6. Run the app

#### Browser (Chrome) — fastest for development

```bash
flutter run -d chrome
```

> First time? Enable web support with:
> ```bash
> flutter config --enable-web
> ```

#### Android emulator / physical device

```bash
# List available devices
flutter devices

# Run on a specific device (use the device id from the list above)
flutter run -d <device-id>

# Or simply let Flutter pick the only connected device
flutter run
```

#### iOS (macOS only)

```bash
flutter run -d ios
```

---

### 7. Build for production

```bash
# Web
flutter build web --release

# Android (App Bundle for Play Store)
flutter build appbundle --release

# iOS (requires Xcode)
flutter build ios --release
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `flutter: command not found` | Add Flutter `bin/` to your PATH (see step 1) |
| `firebase_options.dart` missing | Run `flutterfire configure` (see step 5) |
| Hive adapter errors | Run `dart run build_runner build --delete-conflicting-outputs` |
| `MissingPluginException` on web | Some plugins (AdMob, IAP) are not supported on web — use Android/iOS for full testing |
| Chrome not opening | Run `flutter config --enable-web` then retry |
| Build fails after `flutter pub get` | Try `flutter clean && flutter pub get` |
