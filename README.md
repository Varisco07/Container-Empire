# Container Empire

A mobile container-opening simulator built with Flutter — think CS:GO cases meets Pokémon collection, with deep progression, mutations, and live events.

## Features

- **8 Rarity tiers** — Common → Mythic, each with distinct glow effects and reveal animations
- **5 Mutation types** — RNG-driven item mutations that modify appearance and value
- **Advanced RNG engine** — Luck boosts, event multipliers, and provably fair drops
- **Roulette + Flame Engine animations** — Smooth 60 FPS container opening experience
- **Inventory system** — Filter, search, sort, lock items, sell single/bulk/all
- **Progression** — XP, levels, upgrades, daily/weekly missions
- **Monetization** — Rewarded ads, IAP gem packs, VIP Pass, Battle Pass

## Tech Stack

| Layer | Technology |
|-------|-----------|
| UI | Flutter 3.x + Material 3 Dark |
| Game Engine | Flame 1.17+ |
| State Management | Riverpod 2.x |
| Local Storage | Hive 2.x |
| Backend | Firebase (Auth, Firestore, Functions, Remote Config, Analytics, Crashlytics) |
| Ads | Google Mobile Ads SDK |
| IAP | in_app_purchase |
| Navigation | GoRouter 14.x |
| DI | GetIt 8.x |
| Animations | flutter_animate, Lottie |

## Getting Started

### Prerequisites

- Flutter SDK `>=3.3.0`
- Dart SDK `>=3.3.0`
- Firebase project (see [SETUP.md](SETUP.md))

### Installation

```bash
git clone https://github.com/<your-username>/container-empire.git
cd container-empire

# Install dependencies
flutter pub get

# Generate Hive adapters
dart run build_runner build --delete-conflicting-outputs

# Configure Firebase (required before first run)
flutterfire configure
```

### Run

```bash
flutter run
```

> **Note:** The app requires a valid `lib/core/config/firebase_options.dart` generated by `flutterfire configure`. The placeholder file in the repo will not work.
